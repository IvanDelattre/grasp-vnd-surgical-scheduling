# Registro de consulta das fontes

Consulta realizada em 25/10/2026.

- [Artigo de Soares et al., 2020, PDF de 12 páginas](https://proceedings.science/proceedings/100144/_papers/122642/download/abstract_file2?lang=pt-br): acessível; seções 2, 3, 4 e 5 consultadas para modelo, algoritmo e protocolo.
- [Repositório POACE-Instancias, branch master](https://github.com/elisandrade21/POACE-Instancias): acessível; a árvore pública exibida contém somente `README.md`. Não havia arquivos de instâncias disponíveis na árvore consultada.
- [README oficial](https://github.com/elisandrade21/POACE-Instancias/blob/master/README.md): descreve instâncias, mas não fornece matriz completa de preparações e durações para importação.

O artigo lista COHM-130-S10; o README oficial menciona COHM-130-S6. Esta
divergência foi registrada, sem reconstruir ou escolher supostos dados originais.
A suíte deste projeto usa seis salas para N=130 como escolha sintética explícita.

Nenhum arquivo original foi importado ou estimado. Não há licença de dados
hospitalares a declarar nesta entrega porque não são redistribuídos dados do
hospital nem arquivos do artigo. Os links permitem reavaliar a disponibilidade
futura. Não afirmamos ausência de dados em todo o histórico, branches ou outros
meios de distribuição dos autores.
